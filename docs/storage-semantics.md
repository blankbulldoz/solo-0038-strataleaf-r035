# 数据与兼容边界

物理表包括 meta、collections、versions、commits、receipts、index_defs、index_values、pins、consumers、mirror_sessions、mirror_entries。versions 的主键为集合、键、修订；body 的 SQL NULL 表示删除，JSON null 只能作为文档字段。collections 保存当前模式；index_values 是当前 head 的投影。commits 保存完整的操作序列；receipts 保存不受历史回收影响的请求摘要与结果。幂等键不能被不同操作复用，回放不重新执行前置条件。

floor 是仍可读取的最早修订，不代表每条物理版本的最小修订；每个键在 floor 之前的最后版本可能是构造 floor 读视图的基准，必须保留。commits 仅需保存大于 floor 的提交，消费者从自己的 ack 之后读取。pin 与消费者位置不能低于现存 floor。

模式包含 fields、required、additional，支持点路径类型；additional=false 限制顶层未知根字段，不递归禁止已声明对象中的子字段。字段不允许 null，除非该字段未声明类型；缺失可通过 required 控制。integer 排除 bool，number 接受整数及有限浮点。JSON 对象不允许非字符串键；浮点必须有限。索引忽略缺失字段与对象/数组，空值作为可索引标量，数值 1 和 1.0 共用索引值，true 与 1 不共用。

游标携带数据库身份、谓词摘要、读版本和最后键，并由数据库私有密钥签名。它不是权限凭据，不冻结模式，也不是保留租约。需要稳定的长时间读取，调用者自行管理具名保留点。

副本包是内部可信通道数据，校验和只用于检测传输损坏。正常备份恢复新主库保留逻辑内容而更换身份；副本初始化保留上游身份。分段追赶未完成时暂不提供当前索引，避免最新唯一约束错误约束中间历史视图。目录 epoch 可在没有文档提交时前进，最终空提交包仍能传递新的模式与索引。

分页镜像把来源视图与本地镜像集合视为两套独立事实。mirror_sessions 记录会话名、来源/镜像集合、谓词及其摘要、来源数据库身份、固定目标修订、来源 floor、键边界、阶段（active/rebasing/synced）和凭据；mirror_entries 按会话与键保存已确认的来源修订、本地修订和正文摘要，空摘要代表已撤销墓碑。镜像动作只按键应用 upsert/tombstone，正文摘要不匹配或来源身份不符即拒绝；同一键的每次实质变化都追加新的本地修订，形成可前置的版本链，重复动作凭来源修订加摘要去重。来源修订空间与本地修订空间不混用，因此不能用来源修订号读取镜像行，须用 `Mirror.read_mirror` 读取每键最新本地版本。重启校正以新固定视图全量重扫为准，synced 只能在逐键核对实际本地行后达成；凭据仅描述该固定视图的覆盖范围，不证明也不找回已被回收的中间变化。handoff 令牌与游标共用数据库私有 HMAC 密钥，绑定数据库身份，进程重开后可据令牌重连；abandon 删除会话与台账行（外键级联），不删除镜像集合内的普通文档。
